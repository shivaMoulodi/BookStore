# Web Design Project

This project involves creating a responsive web page layout with the following main sections:

- **Grid Layout**: Establish a four-section layout including Header, Lectures, Related Books, and Footer.
- **Header**: Features a full-width background image with centered text and a button that links to the "Books Related" section.
- **Lectures**: Displays four cards with information about different chapters of a web programming course, styled with a background image and hover effects.
- **Books Related**: Contains cards for books with interactive elements such as hover effects and a popup for more details.
- **Footer**: Includes copyright information and a list of links with hover effects.
- **Menu**: Provides a fixed navigation icon and links to different sections of the page with hover effects.

The project will be deployed on GitHub Pages. For deployment, create a GitHub repository, push your code, and configure GitHub Pages in the repository settings.

## Getting Started

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/web-design-project.git
   ```
2. **Navigate to Project Directory**:
   ```bash
   cd web-design-project
   ```
3. **Open `index.html`**: View the design in your web browser.
